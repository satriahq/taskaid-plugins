# Taskaid plugins

Official Taskaid plugins for AI assistants and coding tools, maintained by Satria Technologies Private Limited.

[Taskaid](https://taskaid.ai) is task management between you and your agents. Work, context and next steps stay connected across conversations and assistants. You need a Taskaid account; there's no API key or local server.

## Cursor

Cursor's agent can read and update your tasks from inside the editor. Park something you noticed mid-change as a task with a day on it, pick a task up by its reference and carry on from its note, and mark it done when the fix is merged.

Add the Taskaid plugin in Cursor, then sign in and approve the access you want to grant. Every action runs as your own account, limited to what you approved. If you added Taskaid to `mcp.json` before, remove that entry so its tools don't appear twice.

To disconnect, turn the plugin off under **Customize** in Cursor, or open [Settings](https://taskaid.ai/settings) and disconnect Cursor under **Connected apps**.

For prompts to try and troubleshooting, see [Taskaid for Cursor](https://taskaid.ai/integrations/cursor). For the tools, see the [MCP server reference](https://taskaid.ai/docs/mcp).
